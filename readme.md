# UI Components

A growing library of reusable UI components showcasing modern frontend development, component architecture, and thoughtful UI design.

## About

This repository contains a collection of reusable UI components that I design and build to explore modern frontend patterns and improve my skills in component architecture, accessibility, and user interface design.


## Tech Stack

Depending on the component, the project may include:

- React
- TypeScript
- Tailwind CSS
- Storybook
- Vite
- Vitest
- ESLint
- Prettier

## Components

The library will continue to grow over time. Planned components include:

- Buttons
- Inputs
- Selects
- Checkboxes & Radios
- Modals
- Drawers
- Tooltips
- Dropdowns
- Tabs
- Accordions
- Toasts
- Tables
- Cards
- Navigation
- Pagination
- Date Picker
- Command Palette
- And more...

## Goals

- Build production-ready UI components
- Follow modern frontend best practices
- Focus on accessibility (WCAG & ARIA)
- Improve component API design
- Document components with examples
- Continuously refine implementation and developer experience

## Status

🚧 This project is actively under development and new components will be added regularly.
