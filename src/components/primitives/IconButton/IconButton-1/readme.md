# IconButton

A lightweight and customizable icon button component showcasing common variants used in modern user interfaces.

## Preview

![IconButton Preview](./preview.png)

## Features

* Multiple visual styles
* Multiple button sizes
* Various color variants
* Different button shapes
* Common interaction states
* SVG icon support
* Built with semantic HTML and modern CSS
* CSS Grid showcase layout

## Technologies

* HTML5
* CSS3
* CSS Grid
* CSS Variables
